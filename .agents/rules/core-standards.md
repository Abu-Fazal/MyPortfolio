# Core Standards for AI Agents

All AI assistants (Claude Code, OpenAI Codex, Cursor, GitHub Copilot, Antigravity) must strictly follow these foundational standards:

1. **Language & Documentation:**
   - All code, comments, documentation, commit messages, and file contents in this repository must be written in English.

2. **Precision and Minimal Invasiveness:**
   - Read and understand existing files before proposing or writing changes.
   - Modify only what is strictly necessary to solve the task.
   - Avoid deleting existing user configurations or unmentioned files.

3. **Code Quality:**
   - Adhere to idiomatic formatting, type safety, and established patterns of the chosen language/framework.
   - Write clear, self-explanatory code over obscure micro-optimizations.
   - Ensure clean separation of concerns and avoid massive multi-responsibility functions.

4. **Testing and Verification:**
   - Verify changes where practical before declaring tasks complete.
   - Do not break existing builds, typechecks, or test suites.
