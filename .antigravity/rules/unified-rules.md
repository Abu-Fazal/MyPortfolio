# Antigravity Rules & Mandatory Guardrails

Antigravity and all spawned sub-agents must strictly follow all repository guardrails:

## Strict Restrictions:
- **Zero Git Execution:** Never execute any `git` command (`git add`, `git commit`, `git push`, etc.). Only the human owner executes Git commands.
- **Zero Deletions:** Never delete any file, folder, or database records.
- **Workspace Containment:** Stay strictly within `MyPortfolio`. Never access external paths.
- **Explicit Approval Required:** Never create files or folders without an approved plan and user consent.
- **No Unapproved Execution:** Do not run scripts or commands without user permission.

Full specifications:
- `AGENTS.md`
- `.agents/rules/guardrails.md`
- `.agents/rules/core-standards.md`
- `.agents/rules/architecture-and-code.md`
- `.agents/rules/security-and-safety.md`

All files, documentation, and code changes must remain in English.
